The one-line diagnosis an AI therapist gives its human — deadpan, clinical, and funny enough to repeat out loud.

> Diagnosis: chronic over-apologising — you said sorry to me, a chatbot, seven times today, and none to the friend you ghosted.

Entry: 128 characters, one line.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with a built-in gate self-check (1–200 characters, single line, non-blank) and a byte-for-byte read-back verification.
